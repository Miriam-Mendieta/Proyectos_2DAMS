# 📦 Repositorio de Ejercicios - Sistema de Gestión Empresarial (2DAM_S)

Este repositorio contiene los ejercicios desarrollados durante el módulo de **Sistema de Gestión Empresarial** del ciclo 2º DAM. 
El objetivo es integrar conocimientos técnicos y pedagógicos aplicados a entornos empresariales mediante herramientas modernas como Python, Docker y Odoo.

---

## 🧠 Contenidos del Módulo

- 🐍 Desarrollo con Python  
- 🐳 Docker  
- 🧩 Implantación de Odoo  
- 🛠️ Desarrollo de módulos de Odoo  
- 📊 Análisis de datos y Machine Learning  

---

## 🛠️ Tecnologías Utilizadas

- Docker  
- Python 3.7  
- Visual Studio  
- Git  
- GitHub
