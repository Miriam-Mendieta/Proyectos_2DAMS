# Proyectos 2DAMS 💻🎮

Este repositorio contiene una colección de proyectos desarrollados durante el segundo año del ciclo de Desarrollo de Aplicaciones Multiplataforma (2DAMS).
Los ejercicios combinan programación, acceso a datos, SGE, diseño de interfaces...
Cada proyecto está pensado para ser reutilizable , con código comentado y documentación clara.

## ✨ Objetivos

- Aplicar conceptos  de programación en proyectos reales y ejrcicios realizados en los diferentes módulos.
- Integrar buenas prácticas de desarrollo y control de versiones

## 📂 Contenido


- Desarrollo de Interfases
- Sistema de Gratión Empresarial
- Acceso a Datos
- Programación Multimedia y  Dispositivos Móviles 


## 🛠️ Tecnologías

- Sql y SQLite 
- Diseño UI/UX
- Figma
- Python
- Docker
